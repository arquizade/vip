# Vault (Layers 2 and 3: Memory and Connections)

The vault holds your knowledge. Layer 2 is the Obsidian vault with full narratives and logs. Layer 3 is the graph built from those notes.

## Contents

| Path | Purpose |
| :--- | :--- |
| `main/` | The Obsidian vault, organized with PARA |
| `graphify-out/` | Graph files generated from `main/`. Do not edit by hand. |

Open `vault/main/` in Obsidian, not the repository root. This keeps the graph files out of your note list.
