# References

Standards the agent loads only when a task needs them. Each file covers one topic and stays short.

Examples:

* `api-conventions.md`: naming, error formats, and versioning rules
* `writing-voice.md`: tone and style for documents you publish
* `code-style.md`: language-specific conventions

Link each reference from the relevant card or from `CLAUDE.md` so the agent knows when to open it.
